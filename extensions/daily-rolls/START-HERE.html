SUCCESS TUTORING PARRAMATTA · VERSION 0.6.3

Reconnect Daily Rolls to Feedback.

This update restores the connection to already-open portal tabs after an extension reload. Combined classes with the same tutor still share a room.

1. Update Daily Rolls

  1. Unzip this download.
  2. Copy all files inside hapana-rolls into the permanent folder used by your existing extension. Replace matching files and include the new files.
  3. Open chrome://extensions and press Reload on Daily Rolls. Confirm 0.6.3.
  4. Close old Daily Rolls tabs. Refresh Hapana and the portal.

Keep the existing extension installation. Removing it can lose its local tutor schedule history. For a first install, enable Developer mode and use Load unpacked on the folder containing manifest.json.

2. Sign in to the portal

Open the portal below and sign in as an admin, in the same Chrome profile as Hapana. The matching portal update must be live.

Open Daily Rolls / Feedback setup ↗

3. Collect the right day

In Hapana, open Schedule → Day, select the date and clear filters. Open Daily Rolls beside Reports (or through Chrome’s Extensions menu).

Before collecting, tick All classes for this day are visible only when the full group-class day is shown. This replaces missing classes; otherwise unseen saved classes are kept.

Wait for Student bookings synced to Feedback in the new Student bookings panel. A saved local tutor schedule is a different confirmation. Use Retry student sync after a temporary failure; if the first connection failed or the two-hour confirmation expired, sign in and press Reconnect and recollect. The extension reads the classes again with a fresh confirmation.

4. Link tutor and student names

Press Link tutors and students and choose the saved date. Select Sai beside Sai Arulanathan, for example. Unique tutor first names link automatically; duplicate names need review.

Exact, unique student full names link automatically. Match any remaining student to the correct portal Member using their full name, parent name, year and Member ID. Unique parent names also match automatically. Manual choices are remembered by default. If a parent has multiple children, review the child attending; turn off Remember for future bookings for a dated-class exception.

5. Refresh Feedback

A tutor with a linked booking today in Sydney sees My schedule / All students beside Parent Feedback. Other tutors get the normal student search. Choose a scheduled student and check their parent recipient before sending.

Collect again after tutor substitutions, new bookings or cancellations. Assessments and one-to-one sessions remain excluded.

Roll printing still works

Choose rooms, preview room/tutor rolls, then print A4 portrait at 100%, single-sided, with browser headers/footers off. Phone and payment columns remain optional. Sync does not change Hapana attendance or bookings, clock shifts or payroll.

The new student sync stores only student names/IDs and class/tutor details on the private portal. Phones, payment details and room choices are excluded; parent contact details come from portal Members. Old local tutor backups still have no student names.

If the switch is missing

  1. Confirm the extension says 0.6.3 and both Hapana and portal tabs were refreshed.
  2. Check the green Student bookings synced to Feedback message, for today’s date.
  3. Open setup and check the tutor’s full Hapana name is linked to the account they use on the portal.
  4. Check student links and refresh the tutor’s Feedback page.

Only a local tutor backup or a tutor-only Time Clock message does not prove student bookings synced. See README.md for details and the separately released Time Clock integration.
